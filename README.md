# Nordic TRMNL

A diy dashboard that is built with the TRMNL software in mind. Can display stuff like the your calendar, reminders or the public transit schedule. This repo is only for the hardware side.

## Parts

- SEEED studio 7.5" monochrome e-ink display
- SEEED studio ePaper driver board
- SEEED studio XIAO ESP32-C3

## Software

I will be using the opensource TRMNL software and will be self-hosting the server. If you are replicating my design but can't self-host there is a one time purchase of 43,95€ to use TRMNL servers.
